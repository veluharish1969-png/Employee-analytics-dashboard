## Project Description

This project presents an interactive Employee Analytics Dashboard created using Microsoft Excel. The dashboard analyzes employee data to provide insights into workforce distribution, employee attrition, departments, and satisfaction levels. Interactive slicers and visualizations allow users to explore the data and identify key patterns.

## Key Insights

- Total Employees: 14,999
- Employees Who Left: 3,571
- Employee Attrition Rate: 23.81%
- Highest Employee Count by Department: Sales
- Employee satisfaction and department distribution were analyzed using the dashboard.
